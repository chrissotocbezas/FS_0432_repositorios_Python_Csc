## Archivo de Python...

1. Para este archivo, es necesario descargar el archivo heat_2d.py 
2. Se debe verificar que en el ordenador se tenga el compilador e intérprete de Python disponible para ejecutar el archivo.
3. La ejecución del archivo puede hacerse desde BASH de Linux o en un editor de código como VSCode para ejecutarlo, desde la terminal con el siguiente comando:

python3 heat_2d.py

¡IMPORTANTE! Aunque se quieran generar los datos para correr en el output.txt, es preferible primero mostrar los archivos en consola y después trasladarlos para el archivo de forma manual, ya que suelen generarse errores si se quieren tomar los datos del programa y pasarlos directamente a la consola.

4. Se puede obtener un gif diferente si se cambia la paleta de colores. En este caso, se hizo una modificación en im, para generar un gif con colores de azules.
